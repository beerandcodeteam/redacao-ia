## Como usar

- Comece pelo anúncio oficial / changelog / paper antes de qualquer secundária.
- Para benchmarks, prefira a fonte que produziu o número (paper, blog do lab) ao invés de re-reportagem.
- Sempre guarde a URL exata do trecho citado — vai virar `[texto](url)` no post.
- Se a fonte oficial estiver vaga, complemente com docs da lib relevante (LangChain/LlamaIndex/HF) e teste mentalmente se o exemplo bate com a realidade da API.
- Para temas Laravel/PHP (lado Beer & Code), Hugging Face e os labs raramente cobrem — caia em docs oficiais Laravel, packages do ecossistema (laravel-boost, prism-php, etc.) e repositórios no GitHub.
